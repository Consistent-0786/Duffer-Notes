# Splunk : 

- Splunk is a software platform to search , analyze , visualize any-kind of machine generated data 
	- **For Example :**  
		- Application Logs 
		- Transaction Logs 
		- Configuration Logs 
		- Authentication Logs 
		- Faulty data / Error's
		- Assets and Identities 
		- Metrices 
		- Incidents 
		- Billing
