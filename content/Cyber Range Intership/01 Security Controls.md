### Security Controls – Overview

- **Security controls** are safeguards used to **protect systems, networks, and data from threats**
- They are defined and standardized by organizations like National Institute of Standards and Technology    
- Widely implemented through frameworks such as NIST Cybersecurity Framework    
- **Key points :**
    - Help **prevent, detect, and respond** to cyber threats        
    - Can be **policy-based, technical, or physical**        
    - Work together as part of a **layered security approach (defense-in-depth)**

### Controls by Type

1. **Administrative (Managerial) Controls**    
    - Policies, procedures, and guidelines that define security practices        
    - Focus on **people and processes**        
    - Examples :        
        - Security policies            
        - Employee awareness training            
        - Risk assessments

2. **Technical (Logical) Controls**    
    - Implemented using **technology and software tools**        
    - Protect systems and data from unauthorized access        
    - Examples :        
        - Firewalls            
        - Encryption            
        - Intrusion Detection Systems (IDS)

3. **Physical Controls**    
    - Protect **physical access** to systems and infrastructure        
    - Prevent unauthorized entry or damage        
    - Examples :        
        - CCTV cameras            
        - Biometric access systems            
        - Security guards

### Controls by Function

1. **Preventive Controls**    
    - Stop security incidents **before they occur**        
    - Examples :        
        - Firewalls            
        - Access controls            
        - Multi-factor authentication
 
2. **Detective Controls**    
    - Identify and alert on **security incidents in real time**        
    - Examples :        
        - Log monitoring            
        - Security Information and Event Management (SIEM)            
        - Intrusion detection systems
  
3. **Corrective Controls**    
    - Fix issues **after a security incident occurs**        
    - Examples :        
        - Applying patches            
        - Removing malware            
        - Reconfiguring systems

4. **Deterrent Controls**    
    - Discourage attackers from attempting an attack        
    - Examples :        
        - Warning banners            
        - Visible surveillance systems

5. **Compensating Controls**    
    - Alternative safeguards when primary controls are not feasible        
    - Example :        
        - Manual review when automation is unavailable

6. **Recovery Controls**    
    - Restore systems and operations **after an incident**        
    - Examples :        
        - Data backups            
        - Disaster recovery plans
