# What is MDCA ?

- Defender for Cloud Apps is a **CASB (Cloud Access Security Broker)** that helps you **secure how users access cloud apps**
	- **Sees which cloud apps are being used :**
		- (Azure, AWS, GCP, Salesforce, Dropbox, SAP, etc)
    
	- **Monitors users :**
		- no matter where they connect from (managed/unmanaged devices, mobile, public Wi-Fi, corporate network)
    
	- **Detects threats :**
		- between users and cloud apps
    
	- **Assesses app security :**
		- tells you which apps are safe or risky
    
	- **Protects sensitive data :**
		- controls data using labels and policies
    
	- **Controls and monitors sessions :**
		- in real time to protect user
    
> **In Simple :**
> -  It let users access cloud apps **safely**, from anywhere, without losing visibility or control
