# Analytic Rules 

- Analytic Rules are your **SIEM use-cases defined via KQL**
- Sentinel comes with over **500 rule templates**
- Limit of **512 rules per workspace**
	
- There are 7 Types of **Analytic Rules :**
	1. Scheduled
	2. Near-Real-Time (NRT)
	3. Fusion
	4. ML Behavior Analytics
	5. Threat Intelligence
	6. Microsoft Security
	7. Anomaly
