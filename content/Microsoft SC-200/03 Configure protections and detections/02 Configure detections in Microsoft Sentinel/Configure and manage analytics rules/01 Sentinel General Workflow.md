
1. **Sentinel**
    - Central security platform that collects and analyzes log data
        
2. **Analytic Rules**
    - Detection logic that looks for suspicious activity in the data
        
3. **Alerts**
    - Created when an analytic rule is triggered
        
4. **Incidents**
    - Sentinel groups related alerts into a single incident
        
5. **Response Paths** (You can select manual or automatic investigation)

	- **Manual Investigation**
        - SOC analysts investigate, validate, and respond
            
    - **Automation Rules → Playbooks**
        - Automation rules trigger playbooks for automatic response
        - Playbooks perform actions like blocking users or sending alerts

> **In Simple :
> 	- **Sentinel turns data into alerts using analytic rules, groups them into incidents, and responds either manually or through automated playbooks.**
