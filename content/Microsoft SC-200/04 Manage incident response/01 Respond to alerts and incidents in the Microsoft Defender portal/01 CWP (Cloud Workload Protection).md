- **Cloud Workload Protection (CWP)** focuses on **real-time security** for workloads that are already running, it detects **threats as they happen**
- It protects workloads running in **Azure**, **AWS (Amazon Web Services)**, **GCP (Google Cloud Platform)** and **on-premises** environments
- Unlike **CSPM (Cloud Security Posture Management)**, CWP is **not about prevention** 
	- it focuses on **active attacks and suspicious behavior**
   
- **It integrates with :**
    - **SIEM**  tools like **Microsoft Sentinel**
    - **XDR** solutions like **Microsoft Defender XDR**

- CWP works for **most resource types**, including :    
    - **Virtual Machines (VMs)**        
    - **Kubernetes platforms** :        
        - **`AKS` –> Azure Kubernetes Service**            
        - **`EKS` –> Elastic Kubernetes Service (AWS)**            
        - **`GKE` –> Google Kubernetes Engine**
        - **App Services**, **databases**, **storage accounts**, etc
