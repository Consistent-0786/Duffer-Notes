# Defender for Databases (Microsoft Defender for Cloud)

- **Defender for Databases** is a more advanced Defender plan within **Microsoft Defender for Cloud**
- It provides **threat protection and vulnerability assessment** for different types of databases in Azure

- Because Azure offers **different database technologies**, Defender for Databases is split into **four separate sub-plans** :

	1. **Azure SQL Databases**    
	    - Platform as a Service (**PaaS**) SQL offering in Azure        
	    - Has its own dedicated Defender plan
        
	2. **SQL Servers on Machines**    
	    - Focuses on **Infrastructure as a Service (IaaS)**        
	    - You manage the virtual machine hosting the SQL Server        
	    - Requires a different Defender plan than Azure SQL
        
	3. **Open-Source Relational Databases**    
	    - Examples: **PostgreSQL**, **MariaDB**, **MySQL**        
	    - Uses a separate Defender plan because these databases work differently
        
	4. **Azure Cosmos DB**    
	    - A **NoSQL / key-value–based** database        
	    - Very different architecture, so it has its own Defender plan
 
## What Defender for Databases Provides

- Defender for Databases protects **Azure database services**
- It has **four sub-plans**, each tailored to a specific database type
- Focuses on **real-time threat detection**
- Some plans also include **database vulnerability assessment**
