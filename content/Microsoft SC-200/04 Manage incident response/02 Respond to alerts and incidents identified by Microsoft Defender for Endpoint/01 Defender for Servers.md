# What is Defender for Servers ?

- Microsoft Defender for Servers is a cloud workload protection service in **Microsoft Defender for Cloud** that secures **Windows and Linux servers using Microsoft’s endpoint security technology** 

## What does it protect / monitor / cover ?

- Windows servers
- Linux servers
- Azure servers
- Multicloud servers
- On-premises servers via Azure Arc
- Server endpoints and workloads

## What does it do ?

- Provides Endpoint Detection and Response (EDR) 
- Delivers antivirus and malware protection 
- Performs Threat and Vulnerability Management
- Monitors suspicious server activity
- Integrates directly with Microsoft Defender for Endpoint

- Offers two plans
    - **Plan 1**: Core Defender for Endpoint capabilities
    - **Plan 2**: Defender for Endpoint + advanced server security features 
        
- **Example :**
	- Normal behavior : 
		- A Linux server runs scheduled workloads with no abnormal process activity
	- Suspicious behavior :
		- A Windows server starts executing unknown binaries and opening unusual outbound connections, triggering EDR alerts 🚨

> **In Simple :**
	- Defender for Servers is **Defender for Endpoint made for servers**, delivered through Defender for Cloud, with extra advanced features available in Plan 2 and flexible licensing options
