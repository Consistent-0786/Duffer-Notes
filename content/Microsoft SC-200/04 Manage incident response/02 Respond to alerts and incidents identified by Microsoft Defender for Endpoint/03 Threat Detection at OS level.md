
- **Threat detection at the OS level :** 
	- It means that **Defender for Servers and Defender for Endpoint monitor** what’s **happening inside the operating system**, ==not just scanning files==
- Instead of relying only on **signatures**, they analyze **VM and process behavior** like (process execution, memory access, credential access, etc)
- Fileless Attack detection :
	- Because of **behavior-based detection**, they can identify **fileless attacks** 
	- These attacks that **run in memory without writing malicious files to disk** , such as tools like Mimikatz executed through scripts or shells
