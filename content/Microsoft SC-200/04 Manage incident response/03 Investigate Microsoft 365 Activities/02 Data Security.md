# What is Data Security ?

- **Data security** helps protect **sensitive data throughout its entire lifecycle**

- It allows organizations to :
	- Understand **how users interact with data**
	- Prevent **unauthorized access, misuse, or data loss**
	- Keep data safe **whether it’s stored, shared, or in transit**
    
## Types of Data Security

- Data security **uses multiple methods to keep information safe :**
	- **Access control** – Controls who can access on-premises and cloud data    
	- **Authentication** – Verifies users using passwords, access cards, or biometrics    
	- **Backups and recovery** – Restores data after failures, corruption, or disasters    
	- **Data resiliency** – Ensures business continuity through proactive recovery planning    
	- **Data erasure** – Permanently deletes data so it cannot be recovered    
	- **Data masking** – Hides sensitive information using proxy characters    
	- **Data Loss Prevention (DLP)** – Prevents unauthorized sharing or leakage of data    
	- **Encryption** – Makes data unreadable to unauthorized users    
	- **Information protection** – Classifies and labels sensitive files and documents    
	- **Insider risk management** – Detects and reduces risky user behavior    

## Data Types That Need to Be Secured

- Effective data security is critical because data theft can lead to **financial loss, identity theft, and reputational damage**

- Common data types that **must be protected includes :**
	- **Personal information** of employees and customers    
	- **Financial data** such as credit card numbers and banking details    
	- **Health information** like diagnoses and test results    
	- **Intellectual property** including patents and trade secrets    
	- **Business operations data** such as supply chain and production processes    
	
- Malicious hackers and **current or former employees** are common causes of data loss, making insider risk management essential

## Data Security Technologies

- Organizations use these technologies to enforce data security :
	- **Data encryption** – Protects data at rest and in motion by encrypting it    
	- **User authentication and authorization** – Confirms identity and enforces correct access rights using RBAC    
	- **Insider risk detection** – Identifies suspicious actions like unusual downloads or external emails   
	- **DLP policies** – Defines how data can be used, shared, and accessed    
	- **Real-time alerts** – Sends immediate notifications about potential data misuse    

> **In Simple :**
> 	**Data security is about protecting sensitive information, controlling who can access it, preventing data leaks, and detecting risks before damage occurs**
