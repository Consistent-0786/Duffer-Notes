# Threats to Data Security

- Threats to data security come from **both outside attackers and inside users**, whether malicious, careless, or affected by disasters
- Protecting data means addressing **people, technology, and events** together

1. **Hacking**
- Hacking is any attempt to **steal, damage, or disrupt data or systems**.  
- Examples include :
	- Phishing attacks
	- Ransomware
	- Unauthorized system access
    
2. **Malware**
- Malware includes **viruses, worms, spyware, and ransomware**
- It is used to :
	- Gain unauthorized access
	- Steal credentials
	- Exploit system vulnerabilities
    
3. **Data Leakage**
- Data leakage happens when data is **shared outside the organization**, either :
	- **Accidentally** (sending sensitive data to the wrong email or public cloud storage)
	- **Intentionally** (unauthorized sharing)
    
4. **Fraud**
- Fraud involves **misusing stolen or compromised data**, such as :
	- Using stolen credit card details
	- Creating fake transactions using compromised accounts
    
5. **Natural Disasters**
- Events like **floods, earthquakes, or hurricanes** can cause data loss
- Without **offsite backups**, organizations may lose critical data and operations

6. **Negligence**
- Negligence occurs when employees :
	- Ignore security policies
	- Share sensitive data with unauthorized users
	- Try to bypass security controls (not malicious, but still dangerous)
    
7. **Theft (Insider Threats)**
- Theft involves **trusted insiders** stealing :
	- Data
	- Money
	- Intellectual property

- Example: An employee copying sensitive files to a USB drive or personal cloud storage
