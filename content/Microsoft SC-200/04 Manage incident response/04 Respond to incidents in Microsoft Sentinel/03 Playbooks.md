- Used to **automate complex tasks**
    - Also referred to as **SOAR (Security Orchestration, Automation, and Response)**
        
- Used to trigger **Azure Logic Apps**    
    - Logic Apps perform the actual automation workflows
        
- Can be **triggered from Automation Rules**
    - Automation Rules act as the **initiator**
    - Playbooks execute the **complex response actions**

>**In Simple :**
>- **Automation Rules start the process, Playbooks do the heavy lifting**
