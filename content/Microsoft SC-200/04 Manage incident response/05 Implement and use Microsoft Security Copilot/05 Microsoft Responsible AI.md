# Microsoft Responsible AI – Core Principles

1. **Fairness** :
   - AI should treat all users equitably
   - Avoid bias in :
     - Decisions
     - Resource allocation
     - Information access

2. **Reliability & Safety** :
   - AI should :
     - Work consistently
     - Behave safely under different conditions
   - Must handle :
     - Unexpected inputs
     - New or unintended use cases

3. **Privacy & Security** :
   - AI systems should :
     - Protect personal and sensitive data
     - Prevent unauthorized access and data leakage
   - Align with data protection regulations

4. **Inclusiveness** :
   - AI should be accessible to :
     - People of all abilities
     - Diverse user groups
   - Design for usability and accessibility

5. **Transparency** :
   - Users should :
     - Understand AI capabilities and limitations
     - Not be misled about what AI can or cannot do
   - Prevent misuse caused by misunderstanding

6. **Accountability** :
   - Humans must :
     - Remain in control of AI systems
     - Be able to audit, monitor, and intervene
   - Ensure clear responsibility for AI outcomes
