# Copilot for Security – Architecture Overview

## Three Pillars for Effective Operation

1. **Organizational Security Data**    
    - It includes logs, metrics, and information from :        
        - Microsoft Defender            
        - XDR            
        - Sentinel            
        - Other security tools
    
2. **Microsoft Threat Intelligence**    
    - Threat data collected by Microsoft        
    - Integrated across security products
        
3. **Copilot Interaction Data**    
    - Prompts and interactions generated by users        
    - Helps Copilot provide relevant outputs

## Interaction Experiences

- **Embedded Experience**    
    - Inside Microsoft security tools (Sentinel, Defender XDR, Intune)        
    - Prompt directly from tool → Copilot → response in tool
        
- **Standalone Experience**    
    - Access via web browser        
    - Interact directly with Copilot outside other tools
### Plugins

- Act as **interfaces** between Copilot and external services    
- Examples :    
    - Sentinel plugin → interact with incidents        
    - Defender XDR plugin → manage alerts or responses        
- Enable both **pre-processing** and **post-processing** of prompts
## Workflow Steps

1. **User prompt**    
    - From embedded tool or standalone Copilot
        
2. **Pre-processing via plugin**    
    - Example: Sentinel plugin prepares prompt for LLM
        
3. **Modified prompt sent to Large Language Model (LLM)**
    
4. **LLM generates response**
    
5. **Post-processing via plugin**    
    - Example: Format response or prepare app commands
        
6. **Response sent back to user**    
    - May include **app commands** to perform actions in tools        
    - Example: Close an incident in Sentinel via Copilot
### Responsible AI & Security with Azure

- Every step validated against **Responsible AI principles with Azure** :    
    - Fairness, reliability, privacy, security, inclusiveness, transparency, accountability
    - Ensures **ethical and secure operation** of Copilot
