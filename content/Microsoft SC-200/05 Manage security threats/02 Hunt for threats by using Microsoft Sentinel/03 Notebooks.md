# Microsoft Sentinel Notebooks

- **Advanced Sentinel feature**    
- Based on **Python Jupyter Notebooks**    
- Used for :    
    - Data analysis        
    - Advanced visualizations        
    - Machine learning        
    - Threat hunting & threat intelligence
## Why Notebooks are Advanced

- Require **basic Python knowledge**    
- More complex than :    
    - Analytic rules        
    - Hunting queries
- Very **powerful but flexible**
## Common Use Cases in Sentinel

- **Threat hunting**    
- **Threat intelligence analysis**    
- Advanced log analysis    
- ML-based investigations
## Requirements for Using Notebooks

- Must create an **Azure Machine Learning workspace**
- This workspace :    
    - is required to run notebooks        
    - **Incurs additional costs** ⚠️
## Why Notebooks Are Powerful

- Use **Python libraries**    
- Can do :    
    - Statistics & numerical computing        
    - Machine learning & deep learning        
    - Custom logic and automation        
- Not limited to Sentinel-only functionality
