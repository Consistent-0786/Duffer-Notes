# Azure Arc

- **Azure Arc** lets you **manage servers, Kubernetes clusters, and databases anywhere** (on-premises, AWS, GCP) **as if they were running in Azure**
- Azure Arc lets you **manage and secure all your resources from Azure**, even if they are **not in Azure**

- **How it works :**
	- You install the **Azure Arc agent** on a VM, Kubernetes cluster, or database
	- Azure creates an **object in Azure Resource Manager (ARM)**
	- That resource becomes **visible and manageable from Azure**
    
- **This Provides us :**
	- **Single panel** to manage Azure, on-prem, and other cloud resources
	- **Central management** (for example, auto-patching VMs from Azure)
    - Same tools and policies everywhere, no matter where the resource runs

- We can apply **Microsoft Defender for Cloud plans**  **using** ==**Azure Arc**== **to non-Azure resources i.e :**
    -  **Defender for Servers** (Azure, on-prem, AWS, GCP)  
    - **Defender for Containers**
    - **Defender for Databases**
