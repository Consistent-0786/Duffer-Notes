## Identity Provider (IdP)

**Definition:**
An **Identity Provider (IdP)** is a centralized service that stores user identities, verifies them, and provides identity services like **Single Sign-On (SSO)**.

**Simple Explanation:**
Think of an IdP as a **central identity database** where all identities are managed from one place.

**Types of Identities Stored:**
- User identities
- External (Guest) identities
- Application identities
- Managed identities
- On-premises synchronized identities

**What an IdP Does:**
- Verifies user identities (Authentication).
- Provides **Single Sign-On (SSO)**.
- Centralizes identity management.
- Simplifies access across multiple applications.
- Supports security features like **Multi-Factor Authentication (MFA)** and **Conditional Access**.

**Why Use an Identity Provider?**
Without a centralized IdP, every application would need to manage its own users, making authentication, security, and access management difficult.

**Microsoft Entra ID**
- Microsoft's cloud-based **Identity Provider (IdP)**.
- Formerly known as **Azure Active Directory (Azure AD)**.
- Stores and manages identities in the cloud.
- Provides authentication and identity services for Microsoft and third-party applications.

💡 **Exam Tip (SC-300):**
- **Identity Provider (IdP) = Stores identities + Authenticates users + Provides identity services (SSO, MFA, Conditional Access).**
- **Microsoft Entra ID is Microsoft's Identity Provider.**
