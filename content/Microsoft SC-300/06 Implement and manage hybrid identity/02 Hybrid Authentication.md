# Hybrid Authentication - Decision Flow 

- Microsoft provides an **official decision-tree diagram** to help determine the best authentication method for a hybrid environment (on-premises AD + Entra ID).
- There is no single "correct" answer - the right method depends entirely on your organization's specific requirements. 
- The decision tree can be walked through repeatedly to evaluate different scenarios/requirements.
