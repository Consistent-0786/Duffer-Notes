# SPL (Search Processing Language) Commands
## Pipe Operator ( | )

- The pipe operator passes the results of one command to the next command — similar to a production line
- **Example :**

```
index=web | stats count BY status
```

## Fields Command

- Fields represent specific data values within events.
	- `fields` → keep only the listed fields
    - `fields +` → same as `fields` (include fields)
    - `fields -` → exclude listed fields
- **Example :**  
1. Keep only selected fields :

```
| fields user ip status
```

2.   Exclude fields :

```
| fields - password, session_token
```

## Table & Rename Commands

### table

- Displays only the fields you specify, in table format
### rename

- Renames fields for clarity

- **Example :**

```
index=web sourcetype=access_combined
| table JSESSIONID, clientip, useragent, referer, bytes
| rename JSESSIONID AS sessionID clientip AS "User IP Address"
```

## Sort Command

- `sort` sorts results in **ascending order** by default
- `sort +field , sort field-name` → ascending  
- `sort -field` → descending ==**only for single field**==
- For multiple fields, separate by spaces after minus symbol 
	- **Example :** 
		- `sort - field-name01 , field-name02 `
- No spaces inside `-(field)` or `+(field)` when sorting one field

- **Example:**
	- Sort by bytes (descending) and status (ascending)

```
| sort -bytes +status
| sort - field-name01 , field-name02
```

## Dedup Command

- `dedup` removes **duplicate events** based on a specific field or fields
- It keeps **only the first occurrence** of each unique value
- **Example :**
	- Remove duplicate `clientip` entries:

```
index=web
| dedup clientip
| dedup user-name , sessionID

```

## Stats Command

- **Perform Statistical Calculation** on the data retrieved by ==search==
- **Example :**
	- `stats (function-name)`
### Stats Functions :

### **01. stats count Function**

- Counts the total number of events.
- **Example :**
1. This will count all the events as specified in search and rename "count" as "Total Events"

```spl
| stats count as "Total Events"
```

2. Counts only events where the field **zipCode** exists

```spl
| stats count(zipCode) as "Events with ZipCode"
```

3. Renames the output column to a more readable name using **`AS` clause** instead of using **`rename command`** in a new line 
	- As in stats command we can directly rename a field using **`AS clause`**

 ```spl
| stats count(zipCode) as "Events with ZipCode"
| stats count as "Total Events"
  ```

4. Groups the results by one or more fields using **`BY` clause**

```spl
| stats count as "Total Events" by nodeName
```

### **02. distinct_count() / dc() Function**

- To get the count of unique values (removing duplicate values) for a given field

- **Example : **

```spl
index-main sourcetype=eventgen
| stats distinct_count(zipCode) as "Number of Zip Codes"
OR
| stats dc(zipCode) as "Number of Zip Codes"
```

### **03. stats sum() / stats avg() Functions**

- **`stats sum()`**

	-  Provides the total sum of numeric field
		- **Example :**
			- Sum duration for all events and rename as TotalCallTime 
			- Group / split this all by partner field
		
    ```spl
    index=main sourcetype=eventgen
    | stats sum(duration) as "TotalCallTime" bu patner
    ```


- **`stats avg()`**

	- Calculates the average (mean) value of a numeric field
		- **Example :**
			- Average duration for all events and rename as AvgCallTime
			- Group/ split by partner field
    
    ```spl
    index=main sourcetype=eventgen
    | stats avg(duration) as "AvgCallTime" by patner 
    ```

### **04. stats list() / stats values() Functions**

- **`stats list()`**

	- Use the list() function to list all values of a given field 
	- Including duplicate values 
	- Limit upto 100 values only 
		- **Example :**
			- List all values in the responseCode field
			- Rename as "Response Codes"
			- Duplicate field values will **be included** if available

```spl
index-main sourcetype=eventgen
| stats values(responseCode) as "Response Codes"
```


- **`stats values()`**

	- Use the values() function to list **unique values** (removes duplicate values) of a given field
		- **Example :**
			- List unique values in the responseCode field
			- Rename as "Response Code"
			- Duplicate field values will **be removed**

```spl
index-main sourcetype=eventgen
| stats values(responseCode) as "Response Codes"
```

### **05. stats - Combining Functions**

- Multiple functions can be combined into a single stats command 
- **Example :**
```spl
index=main sourcetype=eventgen
| stats count as "Total Events", count(zipCode) as "Events with ZipCode", dc(zipCode) as "Number of Zip Codes", sum(duration) as TotalDuration, avg(duration) as AvgDuration by partner
```
