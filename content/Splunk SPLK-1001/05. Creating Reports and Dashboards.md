- In its basic format, you can name Reports and Dashboards using: 
	- <Group Name> <Object_Type> <Description>
	
	1. Group_Name
		- Name of the department using the knowledge object
		- Example: Technology, Sales, infrastructure, finance, etc
	2. Object_ Type
		- Type of object
		- Examples: Report, Dashboard, Alert, Event type, etc.
	3. Description
		- A description of what the object does
		- Examples: DailyFailures, WeeklyCount

- **Combined Example :** 

``` spl
Example: Technology_Dashboard_TopHourlyFailures

```
## Note :
- Compulsary to use `_` which defining name
	- Example : 
		`Technology_Dashboard_TopHourlyFailures`

- `Group_Name`		 = Technology
- `Object_ Type`	 = Dashboard
- `Description`   	 = TopHourlyFailures
