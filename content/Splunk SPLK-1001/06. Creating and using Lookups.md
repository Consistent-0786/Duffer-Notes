# Overview of Lookups

- A lookup is a way to enrich (add new fields) your data from a lookup table

## Types of Lookups :

1. **CSV (File-Based) Lookups :**
	- External fields are found in CSV files (File-Based)
	- Used for small and Static data sets
	- Most common type of lookup

2. **KV (Key-Value pair) Store Lookups :**
	- External fields are found in a KV Store-collection
	- Use for large lookup tables With data that Changes frequently

3. **External or Scripted Lookups :**
	- Fields are found in an external sources
	- Use python scripts or binary executables to populate fields

4. **Geospatial Lookups :**
	- Add external fields that define boundaries of mapped regions such as :
		- Countries
		- US States
		- US Counties
	- External fields located in 2 file types : 
		- `KML` - Keyhole Markup Language
		- `KMZ` - Keyhole Markup Zipped
