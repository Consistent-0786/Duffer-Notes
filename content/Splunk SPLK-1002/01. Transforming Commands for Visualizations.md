# Visualization Data Structures

- Applying transforming commands creates **Statistics Table** that then create visualizations charts , graphs
- There are Three types of **Statistical Table**
	1. **Single Series** 
		- It contains only 2 columns
	2. **Multi Series**
		- It contains more than 2 columns 
	3. **Time Series**
		- It must include ==Time-column== with other columns

# Types of Visualization

## 1. Charts

- Charts show data trends over time or categories
### Types of Charts

1. **Line Chart** 
	- shows trends over time

2. **Area Chart** 
	- like line chart but filled area

3. **Column Chart** 
	- vertical bars for comparison

4. **Bar Chart** 
	- horizontal bars

5. **Pie Chart** 
	- shows parts of a whole

6. **Scatter Chart** 
	- shows relationship between two values

7. **Bubble Chart** 
	- scatter chart with bubble size representing third value

## 2. Gauges

- Gauges show performance against a range (like speedometers)
### Types of Gauges

1. **Radial Gauge** 
	- circular dial

2. **Filler Gauge** 
	- fills a bar up/down/left/right

3. **Marker Gauge** 
	- shows a pointer/marker on a scale

## 3. Maps

- Maps show data based on geography or location values
### Types of Maps

1. **Choropleth Map** 
	- colors regions (states, countries)
    
2. **Cluster Map / Marker Map** 
	- shows points on a map, clustering when many

## 4. Single Value 

- Show one key metric clearly (a big number)
