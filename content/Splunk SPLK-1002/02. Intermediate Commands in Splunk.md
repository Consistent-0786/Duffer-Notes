# Chart Command - Single series

- It is used to **aggregate and visualize data in a table or chart format**
	- **Example :**
		
```spl
chart <stats-function> over <field>
```

> (stats-function) = stats count , sum , avg , min , max 
 >(field)                = field value , name
 
 ```spl
 index=main sourcetype=eventgen | chart count over nodeName
 
 index-main sourcetype=eventgen | chart avg(duration) over partner
 ```

# Chart Command - Multi-series | Control Arguments

- It **group data by two or more fields**, so that we can compare multiple series in one chart , graph
	- **Example :** 
```spl
chart <stats-function> over <field1> by <field2>
OR 
chart <stats-function> by <field1>, <field2>
```

> **Both commands are same** , just different style of writing

```spl
chart count over nodeName by failureCode
```

## Control Arguments

- Use ==limit== argument to control the number of values in plotted series :
	- To show top 5 values :
		- `limit=5`
	- To show all values : 
		- `limit=0`
- To remove empty **(NULL)** values from series :
	- Argument : 
		`usenull=f`
- To remove **"OTHER"** from series :
	- Argument :
		- `useother=f`

- **Example :**
```spl 
index=main sourcetype=eventgen
| chart count over nodeName by failureCode limit=5 useother=f
```

```spl
index=main sourcetype=eventgen
| chart count over nodeName by failureCode limit=5 usenull=f
```

# Timechart Command – Single series

- The **timechart** command is used to create **time-based charts**
- It automatically creates **time buckets** (per minute, hour, day, etc.)     
	- **Example :**
		- It produces **one series** (single-value trend over time)

```spl
timechart <stats-function>
```

- Count Events Over Time
- Shows how many events occurred in each time bucket

```spl
index=main sourcetype=eventgen
| timechart count
```

- Average Duration Over Time
- Shows the **average value of the `duration` field** over time
```spl
index=main sourcetype=eventgen
| timechart avg(duration)
```

---

# Timechart Command – Multi-series | Control Arguments

- The **timechart** command can create **multiple series** by grouping values using the **BY** clause
- Each unique value of the field becomes a **separate line/series** in the chart
	- **Example :**

```spl
timechart <stats-function> by <field>
```

- Count Events by nodeName

```spl
index=main sourcetype=eventgen
| timechart count by nodeName
```

- Average Duration by partner

```spl
index=main sourcetype=eventgen
| timechart avg(duration) by partner
```

## Control Arguments

- Use **limit** argument to control the number of values in plotted series :
    - To show top 5 values :  
        `limit=5`        
    - To show all values :  
        `limit=0`        
- To remove empty **(NULL)** values from series :  
    `usenull=f`    
- To remove **"OTHER"** from series :  
    `useother=f`
	
- **Example :**

```spl
index=main sourcetype=eventgen
| timechart count by nodeName limit=5 useother=f usenull=f
```

### Span Argument (span)

- The **span** argument controls the time bucket size
- Example: bucket events every **5 minutes** → `span=5m`
	-  **Example :**

```spl
index=main sourcetype=eventgen
| timechart span=5m count by failureCode
```

# addtotals Command – Format Statistical Table

- The **addtotals** command is used after **stats**, **chart**, or **timechart** to add :
       - **Row totals** (sum across each row)        
    - **Column totals** (sum down each column)        
    - Custom labels for totals        
    - Optional field lists (or apply to all numeric fields)
	- **Example :** 
		- Syntax

```spl
addtotals [row=true/false] [fieldname="<value>"] [col=true/false] [labelfield=<field>] [label="<string>"] <field-list>
```
## Options :

- **row=t** (default)  
    Add a **column** containing totals for each row    
- **fieldname="Total Per Host"**  
    Sets the name of the **row total column**    
- **col=t**  
    Add a **row** containing totals for each numeric column    
- **labelfield=nodeName**  
    Specifies which field will hold the name for the total row    
- **label="Total per Partner"**  
    Sets the label for the **column totals row**    
- **Empty field-list**  
    Applies totals to **all numeric fields**
	- **Example :**
		- Adds **row totals** labeled "Total Per Host"    
		- Adds **column totals** labeled "Total per Partner"    
		- Applies to **all numeric fields** since field-list is empty

```spl
index=main sourcetype=eventgen
| chart count over nodeName by partner
| addtotals row=t fieldname="Total Per Host" col=t labelfield=nodeName label="Total per Partner"
```

# Single-Value Visualization - Gauges

- `gauge` creates a **single-value gauge visualization**
- It tells Splunk how to color the value based on **ranges**
	- **Example :**
		- The gauge will display **successPercentage** as a dial/meter
		- The numbers **0 40 60 100** define **Default color ranges** :

| Range  | Meaning          |
| ------ | ---------------- |
| 0–40   | Red (bad)        |
| 40–60  | Yellow (warning) |
| 60–100 | Green (good)     |
## gauge command
```spl 
|  gauge (field-name) field-value_in_no.
```

```
| table successPercentage
| gauge successPercentage 0 40 60 100
```

# iplocation command

- `iplocation` adds **geographical information** (like Country, Region, Latitude, Longitude, ISP-sometimes) to events based on an IP address

	- **Example :**
		- After `iplocation clientip`, Splunk automatically adds these fields

```
index=web action=purchase
| iplocation clientip
```

- **Example :**
	- example with fields shown , added fields can be use to make chart more informative

```
index=web action=purchase
| iplocation clientip
| fields clientip Country Region Latitude Longitude
```

# geostats command

- `geostats` is like `stats`, but it creates **geo-aggregated data** for maps
- Data must contain latitude and longitude (from `iplocation`)
- No need to define latfield and longfield except they differ from lat and Ion
- Control column count: 
	- `globallimit`   -   same as `limit` command

- **Syntax :**

```
geostats [latfield=<field>] [longfield=<field>] <stats-function> [by <fields>]
```

>Examples of geostats functions : `count`, `sum()`, `avg()`, `dc()`, etc.

- **Example :**

```
index=web sourcetype=access_combined action=purchase
| iplocation clientip
| geostats global limit=5 count by categoryId
```

>`iplocation clientip` → adds **lat** and **lon** fields    
>`geostats` groups data **by location (lat/lon)** and **categoryId**    
>`count` → number of events at each location for each categoryId    
>`global limit=5` → show top 5 highest-count results on the map

# geom command 

- `geom` is used to **draw geographic shapes** (countries, states, provinces, ZIP boundaries, etc) on a Splunk map 
- It works together with `geostats` or any data that contains a geographic **feature ID** (like country code, state code, ZIP code)

- **Syntax :**

```
| geom <feature-class> [featureIdField=<field>] [global=*] [allFeatures=*]
```

Where **feature-class** is a built-in or custom geographic dataset, like:
- `countries`    
- `states    
- `us_counties   
- `zipcodes`    
- custom KML lookup files

- **Example :**

```
| geostats count by Country
| geom countries featureIdField=Country
```

>`geostats` aggregates - counts by **Country**    
>`geom countries` draws the **country shapes** on the map    
>`featureIdField=Country` tells Splunk which field matches the map’s shape ID
  So Splunk fills each country shape with color based on the count

- **Another Example :** 
	- Show US state counts

```
index=web
| stats count by state
| geom geo_us_states featureIdField=state
```

>This draws each **US state boundary**, shaded based on the `count`

# trendline command

- `trendline` calculates **moving averages** or **trend values** for a field and creates a new trend line you can overlay on a chart , ==just like stock-market chart== 
- You use it mainly with **timechart** to smooth the data

- **Syntax :**

```
trendline <trendtype><period>(<field>) AS <newfield>
```

- **Trend types :**
	-  **sma** → simple moving average    
	- **ema** → exponential moving average    
	- **wma** → weighted moving average
    
- **Period**
	- A number between **2 and 10,000**, meaning how many data points to average
    
- **Example :**

```
index=main sourcetype=eventgen callResult=Failure
| timechart span=15m count AS totalFailuresTelc001
| trendline sma5(totalFailuresTelc001) AS Trend
```

> 1. `timechart` creates a 15-minute count of failures → `totalFailuresTelc001`    
> 2. `trendline sma5(...)` calculates a **Simple Moving Average** over the last **5 points**    
> 3. Creates a new field called **Trend**    
> 4. On a chart, **Trend** is a smooth line over the counts    
> 5. **sma5()** means : “average the last 5 time points then another 5 points and so onn"
