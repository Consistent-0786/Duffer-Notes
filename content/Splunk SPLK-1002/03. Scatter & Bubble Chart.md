## Scatter Chart 

- A **scatter chart** compares **two numeric fields**
- It plots :    
    - **X-axis → one numeric field**
	- **Y-axis → another numeric field**
- Used to see **correlation** between two values.
    - **Example :**

```spl
index=main sourcetype=eventgen
| fields duration bytes
```

> **duration** = X-axis    
> **bytes** = Y-axis

==In Simple , it passes two numeric fields to the visualization==
## Bubble Chart 

- A **bubble chart** compares **three numeric dimensions**
- It plots :    
    - **X-axis → numeric field 1**        
    - **Y-axis → numeric field 2**        
    - **Bubble size → numeric field 3** (represents magnitude)
		- **Example :**

```spl
index=main sourcetype=eventgen
| fields duration bytes packets
```

>**duration** = X-axis    
>**bytes** = Y-axis    
>**packets** = bubble size

==In Simple , it passes three / more than three numeric fields to the visualization==
