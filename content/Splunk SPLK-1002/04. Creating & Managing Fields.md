# Fields Extraction with knowledge objects 

- In **Splunk**, _Field Extraction_ means pulling out useful pieces of data from raw logs (like IP address, username, status code)
- A **Knowledge Object (KO)** is a saved Splunk item (like a field extraction, lookup, or dashboard) that can be reused by others
- **Field Extraction with Knowledge Objects** means creating and saving field rules so Splunk can automatically extract fields every time those logs appear
## Field Extractor (FX) Utility

- Found in **Settings → Knowledge → Fields → Open Field Extractions**
- Extract fields using the field extractor
- Extracted fields persist as **knowledge objects** in Splunk
## Field Extraction Methods:

- **Regular Expression (RegEx) :**
	- Fields are extracted using a regular expression
	- Use for ==**unstructured data**==

- **Delimiters :**
	- Data with no headers but fields separate by delimiters, Ex: commas, tabs, spaces
	- Use for ==**structured data**== like CSV files

Got it — here are the **three ways including the “Event Actions” menu”**:

### Ways to Access Field Extraction

1. **Settings Menu :**
	- **Settings → Knowledge → Fields → Field Extractions**  

2. **Event Actions Menu :**
	- Run a search
	- Click on a specific event
    - Click **Event Actions → Extract Fields**  
    
3. **Field Sidebar :**
	- Run a search
	- On the right side under **Fields**, click **Extract New Fields**
