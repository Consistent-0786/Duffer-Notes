# Field Aliases

- A **field alias** is a way to give an existing field **another name** without changing the raw data
- To standardize data from different field names from different indexes, sources , sourcetypes

## To create a Field Alias :

1. Go to **Settings → Fields → Field aliases**
2. Click **Add new**    
3. Choose the **App** where you want the alias
4. Select the **Source type** (or host/source)
5. Enter :
    - **Original field name** (e.g., `usr`)
    - **Alias name** (e.g., `user`)
6. Save
7. ==**And Same steps for other sourcetype**==
8. Make sure the **Alias-name** should be same

## To check newly created Field Aliases :

- **Example :**
	- This will show data from two sourcetypes , eg = linux_secure , eventgen 

```spl
sourcetype="(ip-address)"
```

# Calculated Field 

- Fields evaluated using the eval command saved as knowledge objects in Splunk
- Helps to avoid long, repetitive or complex queries using the eval command
- Calculated fields can only be based on extracted fields, eg= Calculated fields on lookup fields will fail
- Calculated fields only apply to events, not stats tables
- Calculated fields can be used with lookup tables

## To create a Calculated Field :

1. Go to **Settings → Fields → Calculated Fileds**
2. Click **Add new**  
3. Choose the **App** where you want the alias
4. Select the **Source type** (or host/source)
5. Write the eval command 
6. Click Save
