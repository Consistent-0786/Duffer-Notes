# Tags 

- Tags provide names **(like nicknames) to field/value pairs** in your data
	- These tags will show up in events containing the tagged field/value pair
	- Each event and field/value combination can have one or more tags
	- Tags are case-sensitive
- **Syntax :**
	- Search events for **tag with value**

```spl
tag=<tag-name>
```

- Search events for tag with value on specific field

```spl
tag::<field-name>=<tag-name>
```

- **Example :**

```spl 
index=main sourcetype=eventgen tag=DMV
```

```spl
index=main sourcetype=eventgen tag::State=DMV
```

## To create a tag

- Run a search to show your events    
- Click on an event to open the **Event Details** panel        
- Click the down arrow in right side of the event 
- Click on Edit Tag
- Create a Tag
-  Click **Save**

## Managing Tags

Go to **Settings → Fields → Tags** where you can : 
- View all tags    
- Edit or delete tag assignments    
- Add new tags    
- See which field-value they belong to    
- Control tag permissions

# Events Types

- An **event type** is a saved search _filter_ that groups similar events together
	- Categorization system to help make sense of your data
	- Helps to shift through huge amounts of data
	- Can be tagged to group similar event types

> ==**Events Types can be tag , it is a very important aspect for CIM** ==

- **Example :**  
Search for all failed logins and save it as an event type called **failed_login**

- **Syntax :**
	- To view **Event Type**

```spl
eventtype=<name>
```


## Ways to Create an Event Type

- **1. From Search Results (most common)**

	1. Run a search    
	2. Adjust search until it matches events you want    
	3. Click **Save As → Event Type**    
	4. Give a name and description    
	5. Save    

- **2. From Settings (manual creation)**

	1. Go to **Settings → Event types**    
	2. Click **New Event Type**    
	3. Enter:    
	    - **Search string**        
	    - **Name**        
	    - Permissions        
	4. Save    

- **3. From Event Details (quick way)**

	1. Open an event    
	2. Click a field value    
	3. Choose **“Create event type”** (or "Save as event type" depending on version)    
	4. Provide a name    
	5. Save    

## To Tag an Event Type

You can tag an event type so it behaves like a category

- **1. From Search**
	- **Example :**
		- Search using the event type
		- Then click the event type name → **Add Tag**

```
eventtype=failed_login
```

- **2. From Settings**

	1. Go to **Settings → Event types**    
	2. Find the event type    
	3. Click **Edit → Manage Tags**    
	4. Add one or more tags    
	5. Save
