# Workflow Actions 

- **Workflow Actions** are **powerful, configurable knowledge objects that let users interact with event data by creating dynamic links or triggers from field values in search results**
- Workflow Actions are **listed under the event actions**

 - There are Three Types of **Workflow Actions :**
	 1. **GET ->** Retrieve information from external source
	 2. **POST ->** Send field / values to external source 
	 3. **Search ->** Perform Secondary searches with filed / values

## Creating a "GET" Workflow Action

- Go to **Settings -> Fields -> Workflow actions -> New Workflow Action
- Select the **Destination App**
- Provide the **Name** with No spaces and special characters
- **Label** that will appear in the event, 
	- eg =`$clientip$` will be replaced by field value
- **Apply only to following fields** - clientip
- **Action type** is ==**link**== for GET and POST
- **URI** - provide the url of the website 
- **Link method** - select GET / POST

## Creating a "POST" Workflow Action

- First Create a **Event Type** to continue 
- Go to **Settings -> Fields -> Workflow actions -> New Workflow Action
- Select the **Destination App**
- Provide the **Name** with No spaces and special characters
- **Label** that will appear in the event 
- **Apply only to following event types** - you have to create a event type to create POST workflow action
- **Action type** is ==**link**== for GET and POST
- **URI** - provide the url of the website 
- **Link method** - select GET / POST
- **Post Arguments** - in HTTP body
	- title - name of the title, eg = Purchase failure with HTTP POST `$status$` 
	- description - here we are sending all data, eg = `$raw$`

## Creating a "Search" Workflow Action

- Go to **Settings -> Fields -> Workflow actions -> New Workflow Action
- Select the **Destination App**
- Provide the **Name** with No spaces and special characters
- **Label** that will appear in the event 
- **Apply only to following fields** - userIPAddress
- **Show Action** - Both
- **Action type** - Search
- **Search String** - input the search
- **Time range** - can set the Earliest and Latest time
