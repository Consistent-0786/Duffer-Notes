#  Data Models

- It is ==a hierarchical, semantic mapping of your data, organizing raw indexed data into structured, reusable datasets (objects) for easier searching, reporting, and dashboard creation using the== [Pivot tool](https://help.splunk.com/en/splunk-cloud-platform/manage-knowledge-objects/knowledge-management-manual/9.3.2408/build-a-data-model/about-data-models)
- It encode domain knowledge, allowing users to build visualizations **without writing complex SPL (Search Processing Language)** , by defining **parent/child datasets, fields, and relationships**, making data consistent and accessible for security (ES), IT, and other analytics
- It enables non-technical users to create powerful reports via drag-and-drop

## Components of Data Model

### Data sets 

- Data sets are essentially a **collection of events that share common characteristics and fields**
- These datasets are organized in a **parent-child hierarchy**
- data model is composed of one or more **data-sets**

#### Types of Data sets 

##### 1. Root Data set (parent data-set)

- These are the **main data sets** that start the data model 
- **These Data sets are of 3- types :**
	1. **Event datasets** : 
		- It is defined by simple search constraints (eg = `sourcetype=access_*`)
		- These are the most common type and represent a broad category of events 
	
	2. **Search datasets** : 
		- It is defined by a more complex, arbitrary search string that can include transforming commands, often used when the data doesn't map directly to events 
	
	3. **Transaction datasets** : 
		- Used to group related events that occur over a period (e.g., a complete web session), utilizing the `transaction` command logic

##### 2. Child Data sets 

- These **inherit all fields and constraints from their parent datasets** and apply additional constraints to further narrow down the data 
- eg = an `"HTTP Errors"` child dataset might inherit from an `"HTTP Requests"` parent dataset

# To Create a Data Model

- Go to **Settings -> Data models -> New Data Model**
- A new window will open, Add **Title** and **ID** (Auto-generated) and click "Create"

![[Pasted image 20251214163800.png]]

## To Create a Data Model - Add "Root Events" Datasets

- First select **Datasets :  -> Root Event** 
- A new window will appear, Provide a **Dataset Name**, 
- provide a **Constraints** -> **SPL search term** (only the main like index , sourcetype , nothing else )
- Click **Preview** , **Save**

![[Pasted image 20251214165417.png]]

## To Create a Data Model - Add a "Root Search" Dataset 

- First select **Datasets :  -> Root Search** 
- A new window will appear, Provide a **Dataset Name**, 
- provide a **Constraints** -> **SPL search** (with transforming commands , eg = stats commands)
- Click **Preview** , **Save**

# Adding Fields to a Data Model 

## Fields 

 - Fields are key-value pairs (`src_ip`, `user`, `http_method`) that organize data, coming from **[Auto-extracted fields](https://www.google.com/search?client=firefox-b-d&q=Auto-extracted+fields&ved=2ahUKEwjsz6XHhL-RAxVRVmwGHdeDLfsQgK4QegQIARAB)**, **[Regular Expressions](https://www.google.com/search?client=firefox-b-d&q=Regular+Expressions&ved=2ahUKEwjsz6XHhL-RAxVRVmwGHdeDLfsQgK4QegQIARAC)**, **[Lookups](https://www.google.com/search?client=firefox-b-d&q=Lookups&ved=2ahUKEwjsz6XHhL-RAxVRVmwGHdeDLfsQgK4QegQIARAD)**, and **[Eval Expressions](https://www.google.com/search?client=firefox-b-d&q=Eval+Expressions&ved=2ahUKEwjsz6XHhL-RAxVRVmwGHdeDLfsQgK4QegQIARAE)** 
- These fields define the structure for data, allowing users to easily analyze and visualize information across different datasets

## Types of Fields 

### 1. Auto-Extracted Field

- Extracted automatically by Splunk during indexing or search time (eg = `_time`, `host`)

#### To Create Auto-Extracted Field

- Go to **Data Model** window 
- Click on **Add Fields** on right-hand side
- Select **Auto-Extracted**

![[Pasted image 20251215124925.png]]

- Now select **Fields** to add 
- Select the **Field type** 
	- **String** (alpha-numeric)
	- **Number** (numeric)
	- **Boolean** (true/false) 
	- **IPV4** (IP Address)
- Select **Field Flags** :
	- **Optional** 
		- doesn't have to appear in every event
	- **Required** 
		- only events with field are returned in pivot tool
	- **Hidden** 
		- not displayed to pivot users when they select corresponding dataset
	- **Hidden & Required** 
		- Only return events containing field
		- Fields hidden from use in pivot
- Click **Save**
